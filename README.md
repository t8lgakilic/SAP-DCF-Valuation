# SAP DCF Valuation

## Overview

This project presents a complete Discounted Cash Flow (DCF) valuation model for SAP SE.

The model forecasts future financial performance, estimates Free Cash Flow to Firm (FCFF), calculates the Weighted Average Cost of Capital (WACC), and derives the intrinsic value of the company.

---

## Key Features

- Historical financial analysis
- Revenue forecasting
- FCFF calculation
- WACC estimation
- Terminal Value (Gordon Growth)
- Enterprise Value
- Equity Value
- Intrinsic Share Price
- Sensitivity Analysis
